**Collatz Truncation: Complete Proofs and Open Problems** ·
作者：Junjie Zeng（吉林大学物理学院，11260724）

> 按「二进制位长」截断考拉兹轨道的算子 $T_d$，以及它产生的集合 $M_d$、$A$ 的结构、计数与密度。
> 主要结果：$\boxed{M_1=A}$（原手稿中的猜想，本文给出完整证明）、修正覆盖定理

## 1. 摘要

设 $T$ 为考拉兹映射，$n(x)=\lfloor\log_2x\rfloor+1$ 为 $x$ 的二进制位长。对 $d\in\mathbb Z^+$
定义**截断算子**：自 $x$ 出发沿 $T$ 迭代，当「除以 2」的次数**首次**达到 $d\,n(x)$ 时停止
（该步必为除以 2），其值记为 $p_d(x)$，并令

$$M_d=\{p_d(x):x\in\mathbb Z^+\},\qquad
A=\{m\in\mathbb Z^+:3\nmid m,\ \exists k\ge1,\ 3^k/2<m<3^k\}.$$

本文（借助数值核验与逐行人工审校）给出下列**完整证明**：

| 编号 | 结论 |
|---|---|
| 定理 2.2 | 截断条件对任意 $x,d$ 在前 $2d\,n(x)+1$ 步内必被满足 |
| 定理 2.4 | 对一切 $x,d$：$3\nmid p_d(x)$，即 $M_d\cap3\mathbb Z=\varnothing$ |
| 推论 2.5 | 原手稿的猜想 $M_d+3\mathbb Z=\mathbb Z^+$（$d\ge2$）**为假** |
| 定理 3.1 | 修正覆盖定理：$M_d+3\mathbb Z=\{m\in\mathbb Z^+:3\nmid m\}$ 对一切 $d\ge1$ |
| 定理 4.2 | 分层计数：$\#A_k=3^{k-1}$，$A(3^K)=A(3^K-1)=\dfrac{3^K-1}{2}$ |
| 命题 4.3 | 精确公式（上半层）：$A(N)=\left\lceil\dfrac{2N}{3}\right\rceil-\dfrac{3^{K-1}+1}{2}$，误差项 $\varepsilon(N)=\dfrac{(N\bmod3)-1}{3}$ |
| 定理 4.4 | $\displaystyle\limsup_{N\to\infty}\frac{A(N)}{N}=\frac12$，$\displaystyle\liminf_{N\to\infty}\frac{A(N)}{N}=\frac13$（自然密度不存在） |
| 定理 4.6 | 三分结构：$3A+1\subseteq A^{(1)}$、$3A+2\subseteq A^{(2)}$，两个包含均严格 |
| 定理 5.2 | $M_1\subseteq A$（两个全程正性的辅助量 $S,R$） |
| 定理 6.2 | $A\subseteq M_1$（反向考拉兹构造，取 $x=y_k2^{t_k}$） |
| **定理 6.3** | **$\boxed{M_1=A}$** |
| 推论 6.5 | 无条件地 $1\notin M_1$ |
| 推论 6.4 | 令 $C=M_1$，则 $C$ 与 $A$ 有相同的上下极限 $\tfrac12,\tfrac13$ |

仍在开放的问题：

* **猜想 7.1**：$\bigcup_{d\ge1}M_d=\{m:3\nmid m\}$ 是否成立？（数值上未见反例；原手稿提出的候选
  $13$ 已被否证——取 $x=86$ 得 $p_2(86)=13$）
* **问题 4**：$d\ge2$ 时 $M_d$ 的精确刻画、渐近密度、$M_d$ 是否无限、$M_d$ 关于 $d$ 的单调性。
  其中命题 7.4 给出一个结构性事实：若 $d\,n(x)>H(x)$（$H(x)$ 为轨道首次到达 $1$ 所需的折半次数），
  则 $p_d(x)\in\{1,2\}$；由此 $q_d(2^t)\to\infty$，且 $d$ 越大 $M_d$ 越薄。

### 关于「平均密度 $5/12$」的口径

$5/12=\tfrac12(\tfrac12+\tfrac13)$ 是**上下极限的算术平均**（本文的定义），它**不等于**比商在一层上的
两种自然平均——对数平均为 $\dfrac{2\ln2}{3\ln3}\approx0.42062$，Cesàro 平均为
$\dfrac12+\dfrac12\ln\dfrac32-\dfrac14\ln3\approx0.42808$（见注 4.5）。引用时请注明口径。

## 2. 与原始手稿的关系

原始手稿《一个猜想》（`一个猜想.docx`）提出上述截断法则、集合 $A$、覆盖猜想与 $T(C)=C$。
本文（第五版之后的「完整证明」版）在原稿基础上做了三类工作：

1. **证明**原稿遗留的猜想：$M_1=A$（原稿只给出 $M_1\subseteq A$ 的思路与数值支持）；
2. **更正**原稿的错误：覆盖猜想 $M_d+3\mathbb Z=\mathbb Z^+$ 实为假，正确形式是
   $M_d+3\mathbb Z=\{m:3\nmid m\}$；并澄清原稿的 $T$ 指**截断映射** $p$ 而非考拉兹映射，
   故 $T(C)=C$ 与本文的 $T(C)\not\subseteq C$（$T(2)=1\notin C$）并不冲突，$p(C)=C$ 仍未证；
3. **整理**原稿的记号：参数统一为 $d$、集合写作 $M_d$、幂次判据改用 $\kappa(m)$，并给出逐段符号审查
   （见 `notation_audit_一个猜想.md`：原稿有 4 个符号使用前未定义、9 组一字母两义、3 个死符号）。

> 数值核验一律**不构成证明**；本文所有「定理」都附有完整书面证明，"数值核验"仅用于发现问题与佐证。

## 4. 快速开始

**读论文**：直接看 `考拉兹截断_完整证明.pdf`；投稿请用 `.tex`
（本机无 TeX 引擎，PDF 由 `.tex → .docx → LibreOffice` 生成，公式为 Unicode 近似排版）。

**核验论文里的数值断言**（纯标准库，无需第三方依赖）：

```bash
python code/verify_paper.py          # A0–A10：位长一致性、闭式、计数、p_1(x)∈A、3∤p_d、见证元、比商极值…
python code/scan_gap.py --ds 1,2,3,6,12 --rs 100,1000,10000,100000 --cap 100000
python code/union_scan.py --r 100000 --D 12 --m 13 --cap 300
```

**校验 PDF 的防伪层**：

```bash
python verify_pdf.py --input "考拉兹截断_完整证明.pdf"
```

**重新生成整条流水线**（需要 python-docx、PyMuPDF，以及 LibreOffice）：

```bash
python tex2docx.py                                  # .tex → .docx
# .docx → 无水印 PDF（用本机 LibreOffice，命令行示例见 防伪说明.md）
python make_protected_pdf.py --input plain.pdf --output "考拉兹截断_完整证明.pdf"
python verify_pdf.py --input "考拉兹截断_完整证明.pdf"
```

## 5. 数值证据一览

| 事实 | 数据 |
|---|---|
| 闭式 $A(3^K)=(3^K-1)/2$ | $K\le12$ 全部成立 |
| 分层计数 $\#A_k=3^{k-1}$ | $k\le10$ 全部成立 |
| $p_1(x)\in A$ | $x\le2\times10^5$ 无反例 |
| $3\nmid p_d(x)$ | $x\le2000,\ d\le12$ 无反例 |
| $M_d\cap\{1,2,3\}$ | $d=1$：$\{2\}$；$d\ge2$：$\{1,2\}$ |
| 最小缺口 $g_2(r)$（$d=2$，$x\le r$ 未被取到的最小非 3 倍数） | $r=10^2,10^3,10^4,10^5,10^6,3\times10^6$ 时依次为 $7,25,68,268,1060,1834$（未见停滞） |
| $13$ 的反例搜索 | $p_2(86)=13$（第 14 次折半，$n(86)=7$），故 $13\in M_2$，原候选被否证 |
| 截断落入 $1\to4\to2\to1$ 循环的 $x$ 占比（$x\le20000$） | $d=1,2,3,6,12$ 时为 $0.1\%,7.7\%,30.2\%,70.1\%,100\%$（反例 0） |
